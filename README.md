# 개인 트래커

## 웹 배포

Vercel 배포 설정과 npm 잠금 파일이 준비되어 있습니다. [초보자용 Vercel 배포·PWA 설치 안내](DEPLOY-VERCEL.md)를 따르세요. 환경변수는 필요 없으며 기존 기능·화면·localStorage 구조는 그대로입니다. 웹 배포와 현재 PC의 로컬 실행은 별개로 사용할 수 있습니다.

React + TypeScript + Vite로 만든 로컬 전용 대시보드입니다. 로그인, 외부 API, 백엔드 DB가 없습니다. `dist/`에 빌드된 앱이 포함되어 있습니다.

## 바로 사용

Windows에서 `실행.cmd`를 더블 클릭하세요. 이 PC의 `http://127.0.0.1:5173/`에서 정적 파일을 제공하고 Edge 앱 창(약 820×700)을 엽니다. 이 정적 파일 제공기는 데이터를 받거나 외부로 보내지 않습니다. Node.js가 필요하며 현재 PC에서는 Codex에 포함된 Node.js를 자동으로 찾습니다.

`실행.cmd`의 바로가기를 바탕화면에 두면 다음에도 바로 열 수 있습니다. 브라우저에서 위 주소를 열어 Edge/Chrome의 앱 설치 메뉴 또는 화면의 '앱 설치' 버튼(설치 가능한 경우 표시)을 사용하면 시작 메뉴에서도 실행할 수 있습니다. 실제 Windows 설치는 사용자가 선택합니다. PWA 창 크기는 설치 후 직접 조절할 수 있습니다.

## 데이터

- localStorage 키: `personal-tracker:v1`, 버전: 1
- `habits`: 이름, 고유 ID, 고정 색상, 배열 순서
- `checks`: 습관 ID → 로컬 날짜(YYYY-MM-DD) → 완료 여부
- `todos`: 로컬 날짜 → 그날의 할 일 배열. 날짜가 바뀌면 새 목록을 표시하며 이전 날짜 데이터는 남습니다. 이전 할 일 열람 UI는 이번 범위에 없습니다.
- `notes`: ID와 텍스트 배열. 현재는 첫 번째 메모만 표시합니다.
- 초기 습관은 `src/data.ts`의 `initialHabits`에서 바꿀 수 있습니다. 초기 체크와 할 일은 비어 있습니다. 이미 저장한 사용자의 데이터에는 초기값 변경이 적용되지 않습니다.
- `repository`가 저장 경계입니다. DB로 이전할 때 비동기 어댑터와 로딩 처리를 연결하면 됩니다.
- 메모를 포함한 모든 변경은 즉시 저장됩니다. 저장 실패 시 화면에 오류와 재시도 버튼을 표시합니다. 손상된 기존 데이터는 덮어쓰지 않습니다.
- 데이터는 사용하는 브라우저 프로필과 주소에 종속됩니다. 다른 브라우저/주소로 열거나 브라우저 저장 데이터를 삭제하면 공유 또는 유지되지 않습니다. 동일한 주소를 계속 사용하세요.

## 사용법

습관 칸을 눌러 체크, 습관 이름을 눌러 수정/색상 변경/삭제합니다. 습관 행의 ↑↓ 버튼으로 순서를 바꿉니다. 할 일은 Enter로 추가하고 텍스트를 눌러 수정합니다. 할 일 순서는 드래그 또는 ↑↓ 버튼으로 바꿉니다. 메모는 자유 입력 즉시 저장됩니다. 자정 및 창 재활성화 시 오늘 날짜를 갱신합니다.

## 개발

Node.js 20.19+ 또는 22.12+ 및 pnpm/npm을 사용합니다.

```sh
npm install
npm run dev
npm run build
node serve.mjs
```

개발 서버와 실행용 서버는 같은 포트(5173)를 사용하므로 동시에 실행하지 마세요. PWA는 프로덕션 빌드에서 동작합니다. 서비스 워커 캐시는 버전 변경 시 `public/sw.js`의 CACHE 이름도 올려주세요. HTTPS 또는 localhost에서 설치/오프라인 기능을 사용할 수 있습니다. 이 버전은 외부 서비스에 배포되지 않았습니다.

구성 요소: `WeeklyHabitTracker`, `HabitRow`, `TodoList`, `FreeNote`, `AddHabitModal` (`src/components/`). 저장 모델과 날짜 처리: `src/data.ts`. 스타일: `src/style.css`. 설치 정보/아이콘/오프라인: `public/`.
